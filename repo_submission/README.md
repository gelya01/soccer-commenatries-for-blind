# Тифлокомментарии и визуализации матчей Euro-2024

Проект посвящён прототипу автоматического русскоязычного тифлокомментирования футбольных матчей по структурированным данным StatsBomb (`events` + StatsBomb 360). Работа выросла из большого исследовательского пайплайна: от стандартизации координат и визуальной проверки событий до формирования эпизодов, отбора важных фрагментов, генерации комментариев через LLM, синтеза аудиодорожки и Streamlit-демо.

## Что было сделано

- Собран пайплайн обработки матчей Euro-2024 на данных StatsBomb.
- Реализована стандартизация координат с учётом стороны команды и тайма.
- Добавлена фильтрация некорректных StatsBomb 360 кадров (`bad_ids`).
- Размечены зоны поля: половины, фланги, центральный коридор, штрафные, вратарские, зоны перед штрафной, углы штрафной, боковые и угловые зоны.
- Сформированы производные признаки для событий и цепочек: направление движения, продвижение к чужим воротам, смена зоны, длинные передачи, вход в штрафную, исходы событий и др.
- Исследованы стратегии группировки событий в эпизоды: `event_only`, `related_only`, `related_cap`, `related_stop_cap`, `time_window`.
- Построена soft-label разметка важности эпизодов: `skip`, `brief`, `must`.
- Обучены и сравнены модели отбора эпизодов: Logistic Regression и CatBoost.
- Сформирован системный промпт для русскоязычной LLM-комментаторa.
- Проведён прогон GigaChat-2-Pro для выбранной стратегии и матчей.
- Собрана аудиодорожка тифлокомментариев через Silero TTS.
- Создано Streamlit-приложение для демонстрации: главная страница, видео-заглушка/демо, аудиодорожка, просмотр визуализаций событий.

## Что получилось

- Лучшей практической стратегией для LLM выбрана `related_stop_cap`: она сохраняет связи StatsBomb через `related_events`, но ограничивает длину цепочек и завершает эпизоды на естественных футбольных стоп-событиях.
- Для матча Германия — Шотландия собрана полная аудиодорожка тифлокомментария.
- Подготовлены визуализации событий с актёром, направлением действия, 360-контекстом и видимой областью.
- Создан прототип сервиса «Тифлокомментарии и визуализации матчей Euro-2024».

## Что не включено в эту папку

Чтобы репозиторий оставался лёгким, сюда не добавлены:

- сырые и полные обработанные JSON по всем матчам;
- большие `outputs/` с payloads, кешами API и результатами промежуточных прогонов;
- аудиофайлы `.wav`;
- видеофайлы `.mp4`;
- материалы и исходники текста ВКР;
- виртуальное окружение `.venv`;
- служебные LaTeX-файлы (`.aux`, `.log`, `.fls`, `.bcf` и т.д.).

Демо-видео можно позже положить в `demo_media/` или добавить ссылкой в README.

## Быстрый запуск Streamlit-демо

```bash
cd repo_submission
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_match_viewer/app.py
```

Для полноценного просмотра визуализаций приложению нужны подготовленные JSON-артефакты матчей. В рабочем проекте они лежали в `outputs/euro2024_all/processed_json`. В лёгкую папку они не включены из-за размера.

## Основные ноутбуки

- `euro2024_top15_clean_pipeline.ipynb` — скачивание/стандартизация матчей, bad_ids, визуальная проверка.
- `euro2024_multimatch_chain_pipeline.ipynb` — обработка всех 51 матчей, признаки, цепочки, train/val/test.
- `chain_grouping_llm_model_experiments.ipynb` — сравнение стратегий группировки, soft-labels, модели отбора.
- `sber_gigachat_strategy_llm_run.ipynb` — прогон GigaChat по LLM payloads.
- `kaggle_silero_tts_from_llm_jsonl_stitch.ipynb` — синтез и склейка аудиодорожки через Silero TTS.
- `survey_audio_feedback_analysis.ipynb` — пользовательская оценка аудиокомментариев.
